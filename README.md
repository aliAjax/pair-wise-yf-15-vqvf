# 法医昆虫检材鉴定签发台

法医昆虫学检材的采样登记与鉴定结论签发工具。检材字段覆盖：采样地点、环境温度、尸体暴露阶段、昆虫种类、发育阶段、采样时刻、保存方式、鉴定备注。

## 业务规则

1. **签发**：结论只能由「授权覆盖该虫种」且「证件在签发时点有效」的鉴定人签发；任一项不合，检材**退回待鉴定**并在轨迹中记录原因。
2. **确认**：签发后进入「待确认」，确认时按签发瞬间冻结的**证件快照**复核；证件在确认前已失效的同样退回。
3. **已生效**：结论生效后永久归档保留，不再受鉴定人证件后续状态影响。

页面右上角的系统时钟可前调，用于演示「确认前证件失效」（例如待确认的 S003 在 2026-10-01 后确认将被退回）。

## 预置数据

- **五名鉴定人**：授权虫种范围与证件有效期各不相同，其中顾长庚证件已过期、林知夏证件临近到期。
- **三个案件批次**：城郊林地无名尸案、河湾废弃工棚命案、高架桥下出租屋案，共 12 份检材（待鉴定 / 待确认 / 已生效 / 曾被退回 四种情形均有）。

## 视图

- 签发工作台：批次侧栏、发育阶段筛选、状态队列、检材卡片
- 案件批次：批次详情与案件—检材关联
- 温度记录图：环境温度 × 采样时刻的纯 SVG 图，随批次/阶段筛选联动
- 鉴定人证件：证件有效期、授权虫种矩阵
- 检材详情卡：八项字段、签发预检、确认/撤回、流转轨迹

批次列表、阶段筛选、温度图、案件关联与详情卡共用同一份本地数据（localStorage 持久化，可一键重置）。

## 分层结构

```
src/
  types.ts               领域类型
  rules/signing.ts       规则层（纯函数：授权/证件/签发/确认校验）
  store/archive.ts       存档层（localStorage、订阅、业务动作）
  data/constants.ts      预置鉴定人、批次、检材
  ui/                    界面层（工作台、温度图、详情卡等）
```
